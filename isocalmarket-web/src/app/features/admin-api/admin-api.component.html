Tài liệu tích hợp B2B Admin API

Cổng kết nối đặc quyền dành cho quản trị hệ thống và đối soát thành viên B2B

1. Lấy danh sách thành viên B2B

Trả về danh sách thành viên trên hệ thống bao gồm hồ sơ, vai trò, số dư ví hiện tại và trạng thái khóa API. Hỗ trợ phân trang (?page=1&limit=10), tìm kiếm (?search=...), lọc theo vai trò (?role=...) và trạng thái API Key (?has_api_key=yes/no).

GET /api/v1/admin/b2b/users
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/admin/b2b/users?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/admin/b2b/users?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
Tham số URL (Query Parameters)
api_key
Bắt buộc String

Khóa API Key của Admin để xác thực. Có thể truyền qua query parameter hoặc header X-API-KEY.

page
Tùy chọn Numeric

Số trang cần lấy dữ liệu. Mặc định là 1.

limit
Tùy chọn Numeric

Số lượng thành viên hiển thị trên mỗi trang. Mặc định là 10.

search
Tùy chọn String

Từ khóa tìm kiếm theo tên, email hoặc số điện thoại thành viên.

role
Tùy chọn String

Lọc theo vai trò của thành viên. Nhận giá trị: admin hoặc customer.

has_api_key
Tùy chọn String / Boolean

Lọc theo trạng thái đã sinh API Key B2B hay chưa. Nhận giá trị: yes/no hoặc 1/0.

2. Lấy danh sách đơn hàng B2B toàn hệ thống

Truy xuất thông tin tất cả đơn hàng đã mua qua kênh B2B của mọi thành viên. Hỗ trợ phân trang (?page=1&limit=10), tìm kiếm (?search=...), lọc theo trạng thái (?status=...) và đại lý (?user_id=...).

GET /api/v1/admin/b2b/orders
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/admin/b2b/orders?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}&page=1&limit=10"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/admin/b2b/orders?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}&page=1&limit=10
Tham số URL (Query Parameters)
page
Tùy chọn Numeric

Số trang cần lấy dữ liệu. Mặc định là 1.

limit
Tùy chọn Numeric

Số lượng đơn hàng hiển thị trên mỗi trang. Mặc định là 10, tối đa là 20.

status
Tùy chọn String

Lọc đơn hàng theo trạng thái. Nhận các giá trị: paid, pending, cancelled.

user_id
Tùy chọn String (UUID)

Lọc đơn hàng của đại lý/thành viên cụ thể dựa trên mã ID tài khoản.

search
Tùy chọn String

Từ khóa tìm kiếm theo mã đơn hàng (`order_code`) hoặc thông tin đại lý (tên/email).

3. Thêm kho sản phẩm (Nhập lô tài nguyên mới)

Thêm dữ liệu kho hàng vào sản phẩm. Có thể gửi nội dung trực tiếp bằng JSON hoặc tải file TXT thông qua multipart/form-data.

POST /api/v1/admin/b2b/products/{{ '{' }}id{{ '}' }}/inventory
Tham số yêu cầu (Parameters)
id
Bắt buộc String (URL)

ID sản phẩm trên URL. Sản phẩm phải thuộc quyền quản lý của bạn.

batch_name
Tùy chọn String (Body)

Tên ký hiệu của lô hàng để dễ phân loại và đối soát (mặc định sẽ tự động sinh theo ngày giờ hiện tại).

content
Bắt buộc* String (Body)

Dữ liệu kho hàng dạng chuỗi nhiều dòng (phân cách bằng dấu xuống dòng \n). Bắt buộc nếu không gửi file.

file
Bắt buộc* File (TXT)

Tải file định dạng văn bản .txt chứa dữ liệu sản phẩm qua multipart/form-data. Bắt buộc nếu không gửi content.

4. Lấy số liệu thống kê hệ thống B2B

Xem tổng quan số liệu hoạt động toàn hệ thống bao gồm: Doanh thu, Đơn hàng, Sản phẩm, Tồn kho khả dụng và Tổng số người dùng.

GET /api/v1/admin/b2b/stats
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/admin/b2b/stats?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/admin/b2b/stats?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
Tham số URL (Query Parameters)
api_key
Bắt buộc String

Khóa API Key của Admin để xác thực quyền truy cập.

start_date
Tùy chọn String (YYYY-MM-DD)

Ngày bắt đầu để tính toán doanh thu và đơn hàng.

end_date
Tùy chọn String (YYYY-MM-DD)

Ngày kết thúc để tính toán doanh thu và đơn hàng.
