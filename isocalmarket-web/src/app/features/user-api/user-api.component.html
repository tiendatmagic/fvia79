Tài liệu tích hợp API B2B

1. Lấy danh sách sản phẩm

Lấy danh sách ID sản phẩm, tên, giá bán và số lượng có sẵn trong kho hàng có hỗ trợ phân trang. Hỗ trợ lọc theo danh mục (?category_id=...), tìm kiếm (?search=...), trang (?page=...) và giới hạn (?limit=...).

GET /api/v1/b2b/products
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/b2b/products?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/products?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
Tham số URL (Query Parameters)
api_key
Bắt buộc String

Khóa API Key của đại lý để xác thực quyền truy cập. Có thể truyền qua query parameter hoặc header X-API-KEY.

page
Tùy chọn Integer

Số thứ tự trang muốn lấy dữ liệu. Mặc định là 1.

limit
Tùy chọn Integer

Số lượng bản ghi tối đa trên một trang. Mặc định là 10.

category_id
Tùy chọn String (UUID)

Mã danh mục sản phẩm cần lọc. Nếu không truyền sẽ lấy sản phẩm từ tất cả danh mục.

search
Tùy chọn String

Từ khóa tìm kiếm theo tên sản phẩm.

product_id
Bắt buộc String (UUID)

Bắt buộc Integer (>= 1)

Tùy chọn String

- quantity: Số lượng >= 1 (Bắt buộc)
