API Key của bạn

Sử dụng API Key này để xác thực khi gọi các B2B API bằng cách truyền trực tiếp trên URL (Query param ?api_key=...) hoặc truyền qua HTTP Header X-API-KEY. Tuyệt đối bảo mật và không chia sẻ khóa này cho người khác để tránh thất thoát tài sản!
API Key: {{ apiKey() || 'Chưa cấu hình API Key' }} @if (apiKey()) { }

Tài liệu tích hợp API B2B

Kết nối trực tiếp qua URL, tự động đồng bộ kho hàng và thực hiện giao dịch
1

1. Lấy danh sách sản phẩm

Lấy danh sách ID sản phẩm, tên, giá bán và số lượng có sẵn trong kho hàng.

GET /api/v1/b2b/products
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/b2b/products?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/products?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
RESPONSE MẪU (JSON) 
[
  {{ '{' }}
    "id": "019f6699-e6d2-70f2-89bd-d3b93946a77d",
    "title": "BM3 Ngâm Full 3 Tài Khoản",
    "category": "BẢNG GIÁ BM",
    "price": 80000,
    "stock": 42
  {{ '}' }}
]

2. Lấy thông tin chi tiết một sản phẩm

Xem thông tin mô tả chi tiết sản phẩm kèm theo số lượng tồn kho khả dụng hiện tại.

GET /api/v1/b2b/products/{{ '{' }}product_id{{ '}' }}
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/b2b/products/PRODUCT_ID?api_key={{
                    apiKey() || 'API_KEY_CUA_BAN'
                  }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/products/PRODUCT_ID?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
RESPONSE MẪU (JSON) 
{{ '{' }}
  "id": "019f6699-e6d2-70f2-89bd-d3b93946a77d",

3. Mua tài khoản sản phẩm

Tự động tạo đơn hàng, thực hiện trừ số dư tài khoản của người sở hữu API Key và trả về thông tin tài nguyên tài khoản (accounts) ngay lập tức.

POST /api/v1/b2b/buy
@if (activeTab() === 'bash') { 
curl -X POST "{{ siteUrl() }}/api/v1/b2b/buy" -H "Content-Type: application/json" -H "X-API-KEY: {{ apiKey() || 'API_KEY_CUA_BAN' }}" -d '{{ '{' }}"product_id": "PRODUCT_ID", "quantity": 1{{ '}' }}'
} @else if (activeTab() === 'cmd') { 
curl -X POST "{{ siteUrl() }}/api/v1/b2b/buy" -H "Content-Type: application/json" -H "X-API-KEY: {{ apiKey() || 'API_KEY_CUA_BAN' }}" -d "{{ '{' }}\"product_id\": \"PRODUCT_ID\", \"quantity\": 1{{ '}' }}"
}
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/buy
Tham số Body (JSON Payload)
product_id
Bắt buộc String (UUID)

Mã ID của sản phẩm bạn muốn đặt mua.

quantity
Bắt buộc Integer (>= 1)

Số lượng sản phẩm muốn đặt mua.

RESPONSE MẪU (JSON) 
{{ '{' }}
  "success": true,
  "order_code": "ORD-20260718-A7F9D2",
  "total_price": 80000,
  "accounts": [
    "10007203940192|pass123|2FA_CODE_KEY"
  ]
{{ '}' }}

4. Lấy thông tin tài khoản & Số dư

Lấy thông tin cá nhân đại lý và số dư ví tiền hiện tại (đảm bảo an toàn không lộ các thông tin nhạy cảm).

GET /api/v1/b2b/me
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/b2b/me" -H "X-API-KEY: {{
                    apiKey() || 'API_KEY_CUA_BAN'
                  }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/me?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}

5. Tra cứu chi tiết đơn hàng

Tra cứu trạng thái, giá tiền và danh sách tài nguyên tài khoản đã mua bằng mã đơn hàng (order_code).

GET /api/v1/b2b/orders/ORDER_CODE
Mẫu gọi API (CURL) 
curl -X GET "{{ siteUrl() }}/api/v1/b2b/orders/ORDER_CODE" -H "X-API-KEY: {{
                    apiKey() || 'API_KEY_CUA_BAN'
                  }}"
URL gọi trực tiếp
{{ siteUrl() }}/api/v1/b2b/orders/ORDER_CODE?api_key={{ apiKey() || 'API_KEY_CUA_BAN' }}
