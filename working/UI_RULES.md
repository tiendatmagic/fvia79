Dự án đã có sẵn file design.md.

Đây là Design System chính thức.

Bắt buộc đọc design.md trước khi sinh code.

Không được tự ý:

- đổi màu
- đổi font
- đổi khoảng cách
- đổi kích thước
- đổi border radius
- đổi icon
- đổi component

Không được tạo UI mới nếu đã có component trong Design System.

Luôn tái sử dụng component hiện có.
